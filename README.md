# Coordinates Display Mod
This is a lightweight, simple coordinate display mod for Minecraft. It features a small frame at the top left of your screen which displays the coordinates of your current position.

**This mod uses [Fabric](https://fabricmc.net/). You will need to download it before using this mod.**

I made this mod due to the challenge of reading through a debug menu to find the coordinates. Most of the information on it I wasn't reading, so I created this mod to combat this.
## How to use
- Just download the latest release [v1.1.0](https://github.com/ezraac/Coordinates-Display-Mod/releases/tag/v1.1.0) and add it to your mods folder.
- The key to toggle the menu is `L`
- Use the sliders to change the **RGB** values of the background
- Use the transparency slider to edit the transparency
- Your settings will be saved too!
